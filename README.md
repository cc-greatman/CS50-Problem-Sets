## Engineering Approach

My focus throughout the course is on developing the ability to:

1. Understand a problem before implementing a solution.
2. Break complex problems into manageable components.
3. Select appropriate algorithms and data structures.
4. Write clear and maintainable code.
5. Test and debug systematically.
6. Understand the underlying behavior of the systems I am programming.
